# Actividad2_DV2_UNIR
Actividad realizada para la asignatura de Desarrollo de videojuegos II en UNIR.

**Objetivo:**

El jugador deberá escapar de un lugar aparentemente abandonado resolviendo los puzles de cada habitación hasta llegar a la puerta final que da a la salida.

**Controles:**
- Teclas WSAD/Flechas o joystick izquierdo de un mando para mover al personaje
- Ratón o joystick derecho de un mando para mover la cámara
- Barra espacio o botón “sur” del mando para saltar
- Tecla E o botón “oeste” del mando para interactuar con objetos
- Tecla ESC o botón “START” del mando para abrir menú de pausa

**Información IMPORTANTE para Debuggear:**

Si se ejecuta el juego desde el proyecto en UNITY, se pueden activar en cada Sala unos Triggers desde el Inspector que por defecto están desactivados. Con estos Triggers activados se abrirán las puertas automáticamente sin necesidad de superar los puzles.<br>
_También se puede ajustar la dificultad de los puzles desde el Inspector en cada uno de los Generadores ubicados en cada Sala._
